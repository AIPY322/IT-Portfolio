How to Troubleshoot Outlook Not Syncing

Environment: Outlook Desktop - Microsoft 365

Issues

  • Work Offline mode is enabled
  • Expired, changed, or out-of-sync password
  • Corrupted Outlook profile

Resolution

Work Offline

  1. When Work Offline is enabled, the status bar at the bottom of Outlook displays Working Offline.
  2. Open the Send/Receive tab.
  3. Under Preferences, select Work Offline to disable it.
  4. Confirm Outlook reconnects and begins sending and receiving mail.
